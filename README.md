# Restaurant Dish Order Management System

This repository contains a C++ Object-Oriented Programming coursework project developed for Chernivtsi National University. The project implements a Restaurant Dish Order Management System, demonstrating core OOP principles such as encapsulation, inheritance, polymorphism, composition, operator overloading, exception handling, and file processing.

Проєкт та весь його інтерфейс (меню, вивід у консоль, робота з користувачами) реалізовані **виключно українською мовою**.

## 🛠️ Як зібрати та запустити проєкт (Building the Project)

Для збірки проєкту вам знадобляться компілятор з підтримкою **C++17** (або новіше) та встановлений **CMake**.

### 1. Компіляція проєкту
1. Відкрийте термінал або командний рядок (cmd) безпосередньо у **кореневій папці** проєкту (там, де знаходяться папки `src`, `include` та файл `CMakeLists.txt`).
2. Послідовно виконайте наступні команди для створення папки збірки та компіляції:
   ```bash
   mkdir build
   cd build
   cmake ..
   cmake --build .
   
### 2. Налаштування ресурсів 
Після успішної збірки виконайте наступні кроки, щоб програма бачила необхідні дані:
1. Перейдіть у папку resources у корені проєкту.
2. Скопіюйте всі файли звідти (`menu.csv` та `users.txt`).
3. Перейдіть у папку згенерованого виконуваного файлу: build -> Debug.
4. Вставте скопійовані файли в цю папку (туди, де лежить ваш .exe файл)

### 3. Вирішення проблем із кодуванням (Якщо не відображається текст)
Оскільки проєкт реалізовано виключно українською мовою, на деяких комп'ютерах (особливо в консолі Windows) або після завантаження з GitHub файли даних можуть змінити кодування, через що замінь меню або користувачів з'являться невідомі символи ("ієрогліфи").

Якщо ви зіткнулися з цією проблемою в консолі або всередині самих файлів `.txt` та `.csv`, виконайте наступні кроки для виправлення:
1. Відкрийте проблемний файл (`users.txt` або `menu.csv`) за допомогою стандартного Блокнота (Notepad).
2. У верхньому меню натисніть Файл (File) -> Зберегти як... (Save As...).
3. У нижній частині вікна, що відкрилося, знайдіть поле Кодування (Encoding) та виберіть зі списку ANSI (або Windows-1251).
4. Натисніть Зберегти (Save) та підтвердіть заміну існуючого файлу.
5. Перезапустіть програму.

## 📚 Генерація документації через Doxygen (Generating Documentation)

Код проєкту повністю задокументований за стандартами **Doxygen** (використано спеціальні коментарі для класів, методів та полів). Ви можете автоматично згенерувати інтерактивну документацію у форматі HTML або PDF.

### Попередня підготовка
Переконайтеся, що на вашому комп'ютері встановлено:
1. **Doxygen** ([Офіційний сайт для завантаження](https://www.doxygen.nl/download.html)).
2. *(Опціонально)* **Graphviz** — якщо ви хочете, щоб Doxygen автоматично намалював красиві графіки зв'язків та діаграми класів (у файлі конфігурації має бути увімкнено `HAVE_DOT = YES`).
